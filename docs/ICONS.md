Source SVGs are kept in `assets/profile/icons/`; generated tiles live in `assets/profile/toolkit/`. Tiles share the Midnight Sakura frame and retain recognizable brand artwork on a neutral background. OpenAI's mark identifies OpenAI; ChatGPT is named in the text. Concepts such as SIEM/SOC and prompt design, and tools without a selected icon, are written as text rather than given invented logos.

Execute / Run `node scripts/refine-assets.mjs` to regenerate the tiles without network access. Preserve the license files and pinned revisions when updating the artwork.
